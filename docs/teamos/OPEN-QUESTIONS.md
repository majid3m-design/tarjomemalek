# تیموس — پرسش‌های باز و موارد نیازمند اعتبارسنجی

این موارد حل‌نشده‌اند و نباید پیشنهادها به‌اشتباه تصمیم تلقی شوند.

## عملیات دفتر
- [ ] فهرست دقیق انواع خدمت/سند در نسخه اول چیست؟
- [ ] برای هر نوع خدمت مراحل و پیش‌نیازهای اجباری دقیق کدام‌اند؟
- [ ] چه کسی می‌تواند مرحله را تکمیل یا تأیید کند؟
- [ ] ددلاین هر سند همیشه لازم است یا ددلاین پرونده کافی است؟
- [ ] وضعیت‌های استاندارد پرونده و سند چه باشند؟
- [ ] یک سند می‌تواند چند نسخه/ترجمه یا چند زبان داشته باشد؟
- [ ] تعداد و ساختار دقیق اسناد مثال جلسه روشن شود؛ شرح اولیه سه سند و تفکیک بعدی یک + دو + یک بود.

## کاربران و همکاری
- [ ] نسخه اول فقط روی گوشی مالک است یا منشی/فرم‌زن هم وارد سیستم می‌شوند؟
- [ ] چند دستگاه باید همگام شوند؟
- [ ] منشی چه اطلاعاتی را می‌بیند و چه تغییراتی مجاز است؟
- [ ] فرم‌زن فقط فایل تحویل می‌دهد یا وضعیت کار را هم ثبت می‌کند؟
- [ ] پرتال مشتری در نسخه اول لازم است؟

## آفلاین و معماری
- [ ] آفلاین دقیقاً شامل کدام عملیات و دستگاه‌هاست؟
- [ ] هنگام قطع اینترنت بین‌الملل، سرور داخل ایران در دسترس فرض می‌شود یا هر دستگاه مستقل کار می‌کند؟
- [ ] همگام‌سازی در LAN، اینترنت ملی و اینترنت بین‌الملل چه سناریوهایی دارد؟
- [ ] راهبرد حل تعارض و ثبت تاریخچه چیست؟
- [ ] بازیابی هنگام گم‌شدن/تعویض گوشی چگونه انجام شود؟
- [ ] فایل‌ها روی دستگاه، سرور یا ترکیبی نگهداری شوند؟
- [ ] چه سطح رمزنگاری و کنترل دسترسی لازم است؟

## مالی
- [ ] سود هفتگی بر مبنای جریان نقدی محاسبه شود یا درآمد/هزینه تعهدی؟
- [ ] هزینه عمومی دفتر چگونه بین پرونده‌ها تخصیص یابد؟
- [ ] پیش‌پرداخت، تسویه مرحله‌ای، بدهی مشتری و بستانکاری همکار چگونه ثبت شود؟
- [ ] تاریخ مبنا برای گزارش هفتگی چیست؟
- [ ] مالیات، کارمزد و هزینه‌های عبوری در MVP چگونه نمایش داده شوند؟
- [ ] معیار سوددهی کانال تبلیغاتی چیست و درآمد هر سرنخ چگونه به کانال وصل می‌شود؟

## اعلان و ارتباطات
- [ ] تعریف دقیق مهم و فوری چیست؟
- [ ] بازه یادآوری قبل از ددلاین چقدر باشد؟
- [ ] ساعات سکوت و جلوگیری از اعلان تکراری چگونه باشد؟
- [ ] کدام رخدادها SMS می‌خواهند؟
- [ ] پیام‌رسان داخلی مورد استفاده و API واقعی آن چیست؟
- [ ] اتصال ایمیل/واتساپ ارزش و امکان فنی قابل دفاع دارد؟

## محصول و MVP
- [ ] تعریف قابل آزمون نسخه اول قابل استفاده چیست؟
- [ ] پیوست فایل و تصویر اسناد در MVP لازم است؟
- [ ] جست‌وجو بر اساس نام مشتری، شماره پرونده، نوع سند و موعد چگونه باشد؟
- [ ] ورود سریع پرونده از تماس/پیام چگونه انجام شود؟
- [ ] گزارش کمپین‌های تبلیغاتی در MVP است یا فاز بعد؟
- [ ] چه داده‌ای باید از روز اول ثبت شود تا مهاجرت بعدی دشوار نشود؟

## مشاور فنی سامان
- [ ] نام کامل/هویت حرفه‌ای و شرکت یا محصولات دقیق او چیست؟
- [ ] محصولات بین‌المللی و ایرانی که واقعاً طراحی کرده کدام‌اند؟
- [ ] شواهد عمومی/دمو/مستندات برای انتساب طراحی به او چیست؟
- [ ] نظر واقعی او از طریق کاربر وارد جلسه می‌شود یا فعلاً فقط نقش مشاور شبیه‌سازی‌شده اجرا می‌شود؟

## اولویت حل
1. تعداد کاربران/دستگاه‌ها و سناریوی آفلاین.
2. انواع خدمت و الگوهای مراحل/پیش‌نیاز.
3. تعریف سود خالص هفتگی و رویدادهای مالی.
4. تعریف هشدار مهم/فوری.
5. تصمیم معماری و انتخاب فناوری پس از نقد مشاور فنی.
