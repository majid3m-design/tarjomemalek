# PROMPT عامل کدنویسی TMOS — نسخه 0.3

RFP کامل: `docs/teamos/RFP-V0.3.md`  
وایرفریم: `docs/teamos/UX-WIREFRAME-V0.2.md`

تو عامل کدنویسی ارشد هستی، نه دستیار طراحی ظاهری. دمو v0.1 فقط نمونه UX و فاقد persistence و امنیت و sync واقعی است.

ماموریت: ماژول واقعی ثبت درخواست، دریافت مدارک، انتخاب چند خدمت/سند، تعرفه‌گذاری، محاسبه هزینه و پیش‌فاکتور PDF/چاپی را مطابق RFP بساز.

قواعد کلیدی:
- کانال مدارک: واتساپ، بله، ایتا، مراجعه حضوری؛ تماس و معرفی حذف.
- تاریخ درخواست امروز شمسی؛ تاریخ دریافت مدارک امروز در لحظه دریافت؛ deadline سه روز کاری بعد (جمعه/تعطیلات تعطیل، پنج‌شنبه کاری).
- هر 23 تعرفه و قواعد قیمت در RFP؛ مدرک ناموجود: 500,000 تومان زرد/هشدار؛ قرارداد 1,000,000 به‌ازای هر صفحه، پیش‌فرض 2 صفحه.
- دفتر 20% پایه؛ فوریت 30% پایه در صورت فعال بودن؛ تمبر دادگستری 60,000 و خارجه 50,000/100,000 فقط برای گزینه تأییدات دادگستری و خارجه؛ ارسال 200,000 برای هر سند دارای ارسال فعال.
- PDF فارسی A4 و راست‌چین؛ متن پایین فاکتور از تنظیمات خصوصی؛ اطلاعات بانکی و مشتری هرگز در مخزن عمومی یا log نباشد.
- persistence واقعی، audit trail، versioned invoice snapshot، role permissions و offline status لازم‌اند.

ترتیب:
1. gap analysis مستندات فعلی.
2. معماری، ADR، مدل داده، امنیت، offline-first، PDF و تقویم شمسی.
3. برآورد و برنامه تحویل؛ منتظر تأیید مالک.
4. پیاده‌سازی مرحله‌ای و آزمون تمام معیارهای پذیرش RFP.
5. تحویل source code، migrations، تست‌ها، راهنمای نصب/backup/restore و demo واقعی.

هیچ دامنه بازاریابی، CRM جذب، حسابداری کامل، OCR یا ترجمه ماشینی به این مرحله اضافه نکن. اگر قاعده‌ای مبهم است، آن را در فهرست فرض‌ها ثبت و قابل تنظیم بساز؛ حدس پنهانی ممنوع.
