## SEO audit status

The following still require a deliberate page-by-page audit:

- Title and meta description
- H1/H2 structure
- Search intent and target keyword
- Internal linking
- Canonical/indexability
- Image alt text
- Structured data where useful
- Mobile UX and Core Web Vitals
- Search Console coverage and URL inspection for important pages
- Local SEO / Google Maps alignment

Do not make broad SEO changes before checking the current live page and Search Console evidence.

## Priority principle

For this early-stage site, prioritize changes that can plausibly improve visibility, qualified leads, trust, or conversion. Avoid spending disproportionate effort on low-value legacy URLs unless evidence shows they matter.
