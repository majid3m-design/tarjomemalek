## Source-control principles

1. Keep reusable front-end source in this repository.
2. Keep WordPress credentials, customer data, uploads, and runtime secrets out of Git.
3. Prefer small, focused commits.
4. Use feature branches for substantial changes.
5. Merge reviewed changes into `main`.
